# Repository Guide

This is a monorepo with two independent projects:

- `backend/` — Java 21 / Spring Boot API. See [backend/AGENTS.md](backend/AGENTS.md).
- `frontend/` — web client (Next.js). See [frontend/AGENTS.md](frontend/AGENTS.md).

Each subproject has its own toolchain, build/verify commands, and conventions documented in its
own `AGENTS.md`. Read the relevant one before working inside that folder; nothing here overrides it.
